# Client Handoff — ChannelPilot AI v20

## Что получает клиент

Закрытого AI-SMM ассистента для Telegram-каналов:

- подготовка новостей и дайджестов;
- редакционные посты по стилю канала;
- медиа из источников с безопасной проверкой;
- расписание и очередь;
- публикация через подтверждение;
- роли пользователей;
- audit log;
- контроль расходов AI.

## Как начать

1. Добавить бота администратором канала.
2. Передать username канала для `ALLOWED_CHANNELS`.
3. Проверить канал командой `/check @client_news`.
4. Выбрать пресет `/preset @client_news classic_news`.
5. Задать редакционную политику `/prompt @client_news | ...`.
6. Создать первый черновик `/news @client_news тема`.

## Важно

Система не гарантирует рост подписчиков, просмотров или дохода. Она автоматизирует подготовку и управление контентом, снижает ручную работу и помогает безопасно вести публикации.

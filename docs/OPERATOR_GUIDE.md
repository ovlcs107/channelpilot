# Operator Guide — ChannelPilot AI v20

## Роли

- owner — полный доступ.
- operator — создаёт черновики, новости, дайджесты, планирует и может публиковать через подтверждение.
- viewer — смотрит статус, очередь, лимиты и audit.

Команды:

```text
/roles
/addoperator 123456789
/addviewer 123456789
/removeoperator 123456789
/myrole
```

## Базовый workflow

```text
/check @client_news
/preset @client_news classic_news
/prompt @client_news | редакционная политика канала
/news @client_news тема
```

После генерации бот показывает черновик. Публикация доступна только через финальное подтверждение.

## Natural Control

Можно писать обычным языком:

```text
Сделай дайджест для @client_news по главным новостям отрасли
Подготовь день контента для @client_news на завтра
Поставь для @client_news пресет serious_media
Покажи расходы
```

## Контроль качества

- `/review draft_id` — проверка текста.
- `/sourcecheck @channel тема` — диагностика источников.
- `/audit @channel` — история действий.
- `/usage` и `/limits` — контроль расходов.

## Экспорт

```text
/export @client_news
```

Экспортирует тему, стиль, промпт, источники и правила канала в JSON.


## Проверка релевантности темы

Если бот не создаёт новость или отклоняет материалы, используйте:

```text
/sourcecheck @client_news Telegram AI SMM
```

В диагностике смотрите строку `Причины отклонения`. Если много материалов отклонено как `не по теме запроса/канала`, уточните запрос или проверьте редакционный prompt канала.

# Demo Runbook

Этот сценарий нужен для безопасного показа ChannelPilot AI потенциальному клиенту или для проверки собственного канала перед боевым запуском.

## Цель демо

За 7–10 минут показать, что система:

- проверяет права канала;
- готовит новости/дайджесты/редакционные посты;
- оформляет материал под Telegram;
- не публикует без подтверждения;
- ведёт журнал действий и расхода AI.

## Подготовка

1. Создайте отдельный тестовый канал.
2. Добавьте бота администратором с правом публикации.
3. Убедитесь, что ваш Telegram ID есть в `ADMIN_IDS`.
4. Укажите канал в `ALLOWED_CHANNELS`.
5. Выполните деплой и проверьте `/doctor`.

## Демо-команды

```text
/check @client_news
/preset @client_news classic_news
/format @client_news markdown_v2
/addpack @client_news ru_world
/sourcecheck @client_news отраслевые новости
/news @client_news актуальная тема
/digest @client_news главные новости
/day @client_news
/usage
/audit
```

## Что проговорить клиенту

- Публикация не происходит сразу: сначала создаётся черновик.
- Канал проверяется по правам пользователя, правам бота и whitelist.
- Источники и медиа проходят фильтрацию.
- Расходы AI можно контролировать лимитами.
- История действий сохраняется в audit log.

## После демо

Предложите один из форматов:

1. тестовый запуск на 1 канале;
2. приватная настройка под 1–3 канала;
3. внедрение под сеть каналов.
